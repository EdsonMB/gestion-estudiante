# Gestión de Estudiantes - C# Windows Forms

Proyecto reconstruido con una interfaz profesional basada en la propuesta visual solicitada.

## Incluye
- Gestión de estudiantes con arreglos paralelos.
- Agregar, modificar, eliminar y limpiar.
- Búsqueda por nombre.
- DataGridView estilizado.
- Estadísticas: total, carrera más común y estudiantes de Medicina.
- Procesamiento de cadenas: longitud, mayúsculas, minúsculas, primera/última letra, subcadena, texto invertido, sin espacios, reemplazo y conteo de vocales.

## Colores principales
- Azul oscuro: RGB(31, 55, 82)
- Azul profesional: RGB(41, 98, 144)
- Azul petróleo: RGB(46, 110, 120)
- Rojo elegante: RGB(180, 58, 58)
- Gris oscuro: RGB(90, 100, 110)
- Fondo: RGB(224, 230, 237)
- Panel: RGB(245, 247, 250)

## Cómo abrir
1. Abra `GestionEstudiante.csproj` en Visual Studio 2022 o posterior.
2. Asegúrese de tener instalado .NET 8 Desktop Runtime/SDK y la carga de trabajo "Desarrollo de escritorio con .NET".
3. Ejecute con F5.
